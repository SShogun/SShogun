## Currently

**[IronVM](https://github.com/SShogun/ironVM)** · *Go / Linux KVM* — built a tiny x86 virtual machine monitor that runs a real-mode guest on one KVM vCPU. The guest prints `Hi`, exchanges the byte `42` with its Go host over port I/O, and halts with a trace of each VM exit.

**[GateHouse](https://github.com/SShogun/GateHouse)** · *Go / gRPC / PostgreSQL* — building a Layer 7 gateway with separate control and data planes, versioned configuration, atomic route updates, and last-known-good snapshots that keep traffic flowing when the control plane is unavailable.

**[Aegis](https://github.com/SShogun/Aegis)** · *Security engineering* — developing a security-event and risk-intelligence platform. OIDC-backed sessions and an independent hybrid ML anomaly pipeline are implemented; full risk integration and tamper-evident audit logging remain in progress.

**Open source** · *OpenTelemetry Collector* — exploring Go observability internals and validating a proposed contribution locally with tests and static checks; not claiming an upstream merge.

## Selected work

**[SATARK](https://github.com/SShogun/Satark.sec)** — a collaborative fintech fraud-analysis prototype built for a national hackathon. FastAPI, Celery and Redis process transaction data; graph analysis finds suspicious networks, while a React/TypeScript interface visualizes relationships.
<sub>`Python` · `FastAPI` · `Neo4j` · `Celery` · `Redis`</sub>

**[RedisForge](https://github.com/SShogun/RedisForge)** — a Go service for exploring Redis beyond basic caching: RedisJSON, RedisBloom, RediSearch, Streams consumer groups, recovery and delivery semantics, tracing, and integration tests with Redis Stack.
<sub>`Go` · `Redis Stack` · `Docker` · `OpenTelemetry`</sub>
